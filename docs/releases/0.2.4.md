# LowPack 0.2.4

LowPack 0.2.4 adds `--verify` / `--no-verify` on `lowpack extract` so extract matches unpack.
Archive format 1.1, manifest schema 2.0, codec policy, profiles, safety limits, and the 0.1.x
migration path are unchanged.

## Install

```console
python -m pip install https://github.com/devkyato/Lowpack/releases/download/v0.2.4/lowpack-0.2.4-py3-none-any.whl
lowpack --version
lowpack doctor
```

The distribution, import package, and command are all named `lowpack`; the
release wheel is `lowpack-0.2.4-py3-none-any.whl`.

## What changed

- Expose `--verify` / `--no-verify` on `lowpack extract` to match `unpack`.
- Synchronize package, citation, archival, README, and documentation version references.

LowPack remains alpha software. Verify important archives in full, test a
restore, and keep another independent copy.
