# LowPack 0.2.3

LowPack 0.2.3 is a presentation and citation maintenance release. Archive
format 1.1, manifest schema 2.0, codec policy, profiles, safety limits, and the
0.1.x migration path are unchanged.

## Install

```console
python -m pip install https://github.com/devkyato/Lowpack/releases/download/v0.2.3/lowpack-0.2.3-py3-none-any.whl
lowpack --version
lowpack doctor
```

The distribution, import package, and command are all named `lowpack`; the
release wheel is `lowpack-0.2.3-py3-none-any.whl`.

## What changed

- Expanded Zenodo metadata into sanitizer-safe overview, capability,
  installation, use, application, limitation, documentation, relationship,
  and citation sections.
- Expanded Citation File Format metadata without asserting a DOI, ORCID, or
  legal name.
- Updated stale release installation links and compatibility wording.
- Added a documentation index, exact CLI-output examples, and a release
  checklist.

LowPack remains alpha software. Verify important archives in full, test a
restore, and keep another independent copy.
